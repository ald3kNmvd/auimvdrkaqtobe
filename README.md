## Видео института
Добавьте файл `institute-review.mp4` в корень сайта рядом с `index.html`.
Этот один файл используется в двух местах:
- как фоновое видео на страницах сайта (автозапуск, без звука, по кругу);
- как обычное видео со звуком и управлением в разделе «Видеообзор института».
Рекомендуемый формат: MP4, H.264, 1920×1080.
